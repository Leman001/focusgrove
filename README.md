# FocusGrove 🌳

Веб-приложение для людей с СДВГ, помогающее фокусироваться на задачах и получать награды за концентрацию.

## Особенности
- **3D-дерево фокуса:** Дерево растет прямо в браузере с помощью Three.js по мере того, как идет время сессии.
- **Мобильный интерфейс (Mobile-First):** Темная тема, эффекты glassmorphism, удобная нижняя навигация.
- **Строгий режим (Page Visibility):** Если свернуть вкладку с приложением — прогресс сбрасывается.
- **Своя система наград:** Никаких навязанных наград. Вы сами придумываете награды и их "стоимость" в минутах фокуса (например, "5 минут рилсов" = 60 минут фокуса).
- **Локальное хранение:** Все данные надежно хранятся в LocalStorage вашего браузера.

## Запуск
Проект представляет собой чистое SPA (Single Page Application) без необходимости собирать бандл.

Вы можете просто открыть файл `index.html` в браузере или запустить локальный сервер:
```bash
cd /Users/nikolayleman/.gemini/antigravity/scratch/focusgrove
npx serve .
```

Перейдите по адресу `http://localhost:3000` (или другому, предложенному `serve`) с мобильного телефона или в режиме мобильного эмулятора в браузере на ПК.

## Технологии
- HTML5 / CSS3 (CSS Variables, Flexbox, Grid, Backdrop-filter)
- Vanilla JavaScript (ES6 Modules)
- Three.js (Процедурная генерация 3D дерева)
