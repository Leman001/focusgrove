# FocusGrove 🌳

Веб-приложение для людей с СДВГ, помогающее фокусироваться на задачах и получать награды за концентрацию.

## Особенности
- **3D-дерево фокуса:** Дерево растет прямо в браузере с помощью Three.js по мере того, как идет время сессии.
- **Мобильный интерфейс (Mobile-First):** Темная тема, эффекты glassmorphism, удобная нижняя навигация.
- **Строгий режим (Page Visibility):** Если свернуть вкладку с приложением — прогресс сбрасывается.
- **Своя система наград:** Никаких навязанных наград. Вы сами придумываете награды и их "стоимость" в минутах фокуса.
- **Локальное хранение:** Все данные надежно хранятся в LocalStorage вашего браузера.

## Запуск
Проект представляет собой чистое SPA (Single Page Application) без необходимости собирать бандл.

Вы можете просто открыть файл `index.html` в браузере или запустить локальный сервер:
```bash
npx serve .
```

Перейдите по адресу `http://localhost:3000` (или другому, предложенному `serve`) с мобильного телефона или в режиме мобильной разработки браузера.

## Технологии
- HTML5 / CSS3 (CSS Variables, Flexbox, Grid, Backdrop-filter)
- Vanilla JavaScript (ES6 Modules)
- Three.js (Процедурная генерация 3D дерева)

### Debug-режим

#### Открыть консоль браузера
```
Windows/Linux: F12 или Ctrl+Shift+I
Mac: Cmd+Option+I
```

#### Проверить на ошибки
- Перейти на вкладку **Console**
- Убедиться, что нет красных ошибок
- Проверить предупреждения (желтые сообщения)

#### Инспектировать элементы
- Нажать на элемент правой кнопкой → **Inspect** (или Ctrl+Shift+C)
- Проверить CSS-стили и вычисляемые значения
- Убедиться, что glassmorphism эффекты применены корректно

#### Отладка JavaScript
- Поставить breakpoint (клик по номеру строки в Sources)
- Запустить действие и отследить переменные
- Использовать **Watch** expressions для мониторинга значений

#### Проверить LocalStorage
- DevTools → **Application** → **Local Storage** → https://localhost:3000
- Просмотреть ключи и значения
- Удалить отдельные ключи для сброса настроек

### Известные проблемы и решения

**Проблема:** Дерево не растет
- 🔧 Проверить консоль на ошибки Three.js
- 🔧 Убедиться, что JavaScript включен в браузере
- 🔧 Попробовать другой браузер (проверить совместимость Three.js)

**Проблема:** Таймер не останавливается при минимизации вкладки
- 🔧 Проверить поддержку Page Visibility API в браузере
- 🔧 Убедиться, что функция `document.addEventListener('visibilitychange', ...)` работает

**Проблема:** Данные теряются после перезагрузки
- 🔧 Проверить, включены ли cookies/LocalStorage в браузере
- 🔧 Проверить, не запущен ли приватный/инкогнито режим
- 🔧 Посмотреть консоль на ошибки при сохранении

**Проблема:** Низкий FPS на мобильных устройствах
- 🔧 Уменьшить качество 3D сцены (LOD - Level of Detail)
- 🔧 Оптимизировать шейдеры Three.js
- 🔧 Использовать requestAnimationFrame вместо setInterval
